## 🧠 Как создавался этот MVP: Методика «Соло-тимлид»

Этот проект — не просто набор файлов. Это результат работы **команды ИИ-агентов**, которой управлял один человек. 

В процессе разработки я столкнулся с классической проблемой: если дать нейросети задачу целиком («сделай мне приложение»), она теряет контекст, путается в ролях и выдает нерабочий код. Тогда я разработал методику **«Соло-тимлид»**.

### 🎯 Суть подхода

Вместо одного универсального чата я создал **виртуальную команду из 6 специалистов**. Каждый агент получил жесткий контракт: что он делает, а что — **категорически не делает**. 

### 🛡 Контроль на стыках

Главная задача Тимлида (менеджера) — не писать код, а **контролировать передачу артефактов**. Именно на стыках ролей возникают самые опасные баги. 


### 🚀 Результат

Благодаря методике мы прошли полный цикл: от сырой идеи до работающего продукта с каталогом, корзиной и шарингом. Я получил не только готовый MVP, но и **воспроизводимую систему**, которую можно масштабировать на любой следующий проект.

# 🎁 GiftBox Studio

**Инструмент для быстрого создания и шаринга подборок подарков.** 
Приложение позволяет владельцам небольших магазинов за пару минут собрать красивую подборку товаров, опубликовать её и поделиться ссылкой с клиентом, а также отслеживать просмотры.

> 💡 *«Собери подборку подарков за 3 минуты, поделись ссылкой — и увидь, что клиент реально открыл».*

## ✨ Ключевые возможности (MVP)

*   **Каталог товаров:** Полный CRUD, поиск, фильтрация по категориям и тегам. Валидация URL-изображений (Base64 запрещен).
*   **Конструктор подборок:** Создание, редактирование, дублирование подборок. Управление порядком товаров кнопками «Вверх/Вниз».
*   **Публичная страница (Share):** Генерация уникального slug при публикации. Отображение товаров в заданном порядке. Встроенная функция «Поделиться» (Web Share API).
*   **Дашборд:** Статистика (просмотры, количество товаров/подборок), фильтрация по темам, быстрые действия.
*   **Локальная аналитика:** Счетчик просмотров публичных страниц.

## 🏗️ Архитектура и особенности реализации

Проект написан на **Vanilla JS (ES6+)** без использования сторонних фреймворков и сборщиков. Это обеспечивает максимальную скорость загрузки и отсутствие зависимостей.

*   **Хранилище:** Данные сохраняются локально в localStorage. Вся работа с хранилищем инкапсулирована в едином модуле StorageService, методы которого асинхронны (что позволяет в будущем безболезненно перейти на реальный бэкенд, например, Supabase).
*   **Роутинг:** Легковесный SPA-роутинг на основе хэша (#/dashboard, #/products, #/collections/:id, #/share/:slug).
*   **Надежность:** Реализована обработка краевых случаев (переполнение QuotaExceededError, битые картинки, поврежденный JSON со сбросом состояния).
*   **Лимиты:** Встроена защита от переполнения (максимум 200 товаров и 50 подборок) с понятными пользователю сообщениями об ошибках.

## 🛠️ Стек технологий

*   **HTML5** — семантическая разметка
*   **CSS3** — кастомные свойства, адаптивная верстка (mobile-first)
*   **JavaScript (ES6+)** — модульная архитектура, асинхронность, работа с DOM
*   **LocalStorage API** — хранение данных

## 🚀 Запуск проекта

Проект не требует установки зависимостей, настройки окружения или использования сборщиков (Node.js, Webpack и т.д.). Это полностью статическое веб-приложение.

### Способ 1: Быстрый старт (для просмотра)
1. Склонируйте репозиторий на свой компьютер:
    git clone https://github.com/Alex-kdr-123/GiftBox-Studio.git
2. Перейдите в папку с проектом.
3. Дважды кликните по файлу `index.html`, чтобы открыть его в вашем браузере по умолчанию. Приложение готово к работе.

### Способ 2: Для разработки (рекомендуемый)
Если вы планируете вносить изменения в код, удобнее всего использовать редактор кода **VS Code** с расширением **Live Server** (чтобы страница автоматически перезагружалась при сохранении файлов).

1. Откройте папку с проектом в VS Code.
2. Установите расширение **Live Server** (автор Ritwick Dey) из маркетплейса.
3. Нажмите правой кнопкой мыши на файл `index.html` и выберите **«Open with Live Server»** (или нажмите кнопку **Go Live** в правом нижнем углу окна).
4. Проект откроется в браузере по локальному адресу (обычно http://127.0.0.1:5500).

## 📋 📋 О проекте простыми словами
Сайт создавался не на коленке, а по четкому плану (техническому заданию).

* **Умная проверка данных:**
 Приложение не даст сохранить товар с пустым названием, неправильной ценой или битой ссылкой на картинку. Оно сразу подскажет, что нужно исправить.

* **Понятные ошибки:** 
Если что-то пойдет не так (например, закончится место в памяти браузера), пользователь увидит простое и понятное сообщение, а не «белый экран» или страшный код ошибки.

* **Удобно для всех:** 
Сделано так, чтобы сайтом было удобно пользоваться с телефона и компьютера, а также для людей с ограниченными возможностями (правильная навигация и подписи для незрячих пользователей).
